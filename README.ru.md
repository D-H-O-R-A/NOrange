## ⚙️ Основные возможности

### 1. OpenVPN-клиент и публичные серверы
- Каталог из более чем 50 публичных узлов OpenVPN по всему миру (Америка, Европа, Азия, Океания) через VPNGate.
- Метрики в реальном времени: задержка (пинг), заявленная пропускная способность, количество активных сессий, IP и протокол (TCP/UDP).
- Поддержка импорта пользовательских файлов `.ovpn` и ручной настройки профилей (хост, порт, логин/пароль).
- Встроенные пресеты DNS (Cloudflare `1.1.1.1`, Google `8.8.8.8`, AdGuard) и защита от утечек DNS.
- Автоматическое переподключение при сбоях (Failover) и системный Kill Switch.

### 2. Hotspot VPN и локальный прокси-сервер
- **Раздача VPN по Wi-Fi:** Маршрутизация зашифрованного трафика через точку доступа (Hotspot) на другие устройства в локальной сети.
- **Встроенный HTTP и SOCKS5 прокси-сервер:** Запуск прокси прямо на Android-устройстве с выбором порта и поддержкой авторизации (RFC 1929 / Basic Auth).
- **Мониторинг активных подключений:** Отображение подключенных клиентов, удаленных хостов, потребления трафика (входящий/исходящий) и логов запросов.
- **Изоляция интерфейсов:** Предотвращение конфликтов маршрутизации между клиентом VPN, шлюзом Hotspot и прокси-сервером.

### 3. Сетевой мониторинг и инспекция сокетов
- **Анализ активных сокетов:** Чтение `/proc/net/tcp` и `/proc/net/tcp6` для сопоставления открытых соединений с установленными приложениями и UID процессов.
- **Оповещение о фоновых соединениях:** Обнаружение постоянных исходящих подключений через нестандартные порты, открытых фоновыми службами.
- **Оценка затухания Wi-Fi сигнала (FSPL):** Расчет приблизительного расстояния до точек доступа по RSSI (дБм) и частоте (МГц).
- **Управление точкой доступа:** Быстрое переключение состояния Wi-Fi Hotspot прямо из приложения.

### 4. Split Tunneling, Mock GPS и виртуальная камера
- **Раздельное туннелирование (Split Tunneling):** Выбор приложений, трафик которых направляется через VPN или напрямую в сеть.
- **Плавающий виджет (Overlay):** Управление туннелями и параметрами поверх любых запущенных приложений.
- **Эмуляция GPS-координат (Mock Location):** Интеграция со стандартным провайдером фиктивных местоположений Android для тестирования.
- **Виртуальная камера для тестирования:** Подмена потока камеры статичным изображением или видео в стандартных вызовах (`IMAGE_CAPTURE`, `VIDEO_CAPTURE`, `FileProvider`) с масштабированием, поворотом, зеркалированием и перспективой в реальном времени.
- **Root-режим (Priv-App):** Возможность установки в `/system/priv-app` или в виде модуля Magisk/KernelSU для исследовательских стендов и эмуляторов.

### 5. Постоянное системное уведомление
- Информационная плашка в шторке уведомлений со статусом туннеля, внешним IP, текущей скоростью загрузки/отдачи и временем сессии.
- Кнопки быстрых действий для отключения или смены сервера без перехода в приложение.

## 🛠️ Сборка и разработка

Требования: Flutter SDK (>= 3.19), Android SDK, Java 17.

```bash
# Установка зависимостей
flutter pub get

# Запуск в эмуляторе Pixel 7
npm run start:android

# Сборка универсального релизного APK
npm run build:apk

# Сборка APK с разделением по ABI (arm64, armeabi-v7a, x86_64)
npm run build:apk:split
```
